# Sales Dataset

This repository contains a sample sales dataset created for practicing data analysis using Excel.

## Dataset

- **File:** Excel_dashboard  
- **Columns:** `Order_ID`, `Order_Date`, `Region`, `Category`, `Sales`, `Profit`  
- **Purpose:** Practice Pivot Tables, Charts, and basic business insights.

## Usage

1. Download the Excel file.  
2. Open in Excel or any spreadsheet software.  
3. Analyze sales by region, category, or over time.
